📖 數字規則 (第一數至第五數) 使用說明

規則輸入框用於自訂題目中的第一數（左邊被運算數）與第二數（右邊運算數）格式。支援的語法如下：

語法 / 符號 說明 範例
~ 或 ～ (範圍) 指定數字範圍
(不用寫一長串逗號，直接在區間隨機選)		 3~9 → 3到9隨機取一數
10~50 → 10到50隨機取一數
1~5/6~10 → 分子1~5、分母6~10
* (星號) 隨機一位數字
(首位自動為 1~9，避免 0 開頭)		 * → 1~9 (個位數)
** → 10~99 (二位數)
*** → 100~999 (三位數)
固定數字 / 混合位數 直接輸入數字代表固定值，或固定特定位數 25 → 固定為 25
2* → 20~29
1** → 100~199
, (逗號) 多選隨機抽選
(每次隨機從逗號清單中抽一種)		 3~9,20~50 → 從兩範圍抽一種
**,*** → 隨機抽二位或三位數
5,10,15,20 → 抽指定倍數
. (小數點) 小數格式
(適用於小數模式)		 **.** → 如 23.45
0.1~0.9 → 範圍小數
0.** → 如 0.78
/ (斜線) 真 / 假分數
(格式為 分子/分母)		 */* → 如 3/7
1~5/7 → 分子1~5、分母7
1/* → 分子固定為 1
+ 與 / 帶分數
(格式為 整數+分子/分母)		 *+*/* → 如 2+1/3 (即 2又1/3)
1~3+1~5/8 → 帶分數範圍
💡 常見題型設定範例：
  • 自訂乘法範圍 (例如 3~9 的乘法)： 第一數 3~9 、 第二數 3~9
  • 二位數加減一位數： 第一數 ** (或 10~99) 、 第二數 * (或 1~9)
  • 指定範圍混合運算： 第一數 10~50 、 第二數 2~9
  • 四則運算 (多步驟運算)： 固定運算選擇「四則運算」，可分別設定第一數至第五數規則（如 第一數 10~50、第二數 2~9、第三數 2~9），支援括號與先乘除後加減。
  • 同分母分數加減： 第一數 1~6/7 、 第二數 1~6/7（可透過「答案約分」選擇答案是否要化為最簡分數）
  • 整數因數與倍數 (六大題型)： 選擇數字類型「整數」並切換整數模式，支援： 1. 單一數字因數、2. 單一數字倍數、3. 兩個數字的公因數、4. 兩個數字的公倍數、5. 兩個數字最大公因數、6. 兩個數字最小公倍數，以及多種混合模式與自由勾選混合。可透過第一數/第二數規則自訂數值範圍（如 10~100、10~50、6~30），並可設定是否排除質數、以及倍數/公倍數要列出的數量。
  • 國小全系列單位換算： 選擇數字類型「單位換算」，完整支援國小一至六年級八大換算類別： 📏 長度換算（公里/公尺/公分/毫米）、⚖️ 重量換算（公噸/公斤/公克/毫克）、🧪 容量換算（公秉/公升/分公升/毫升）、📐 面積換算（平方公里/公頃/公畝/平方公尺/平方公分）、🧊 體積換算（立方公尺/立方公分）、💧 體積與容量(容積)換算（m³/公秉/公升/分公升/毫升/cm³）、⏱️ 時間換算（日/時/分/秒，支援 24 進位與 60 進位整數及有限小數換算）、以及🌟 國小單位綜合大混合（跨類別總複習）。支援自由勾選出現單位、大換小、小換大、複名數換單名數（換小單位或大單位小數）、單名數換複名數（雙格作答）、高難度陷阱題專練、以及中英代號混合等豐富設定。
